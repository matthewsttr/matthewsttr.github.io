# a Why Python for Differential Equations?

Because Python is free. <g>\$ Free \$ as in beer</g>, and free <markUSR>AS</markUSR><markUSW> IN </markUSW><markUSB>SPEECH</markUSB>. There are CAS systems, like Maple, Mathematica, etc, which are more powerful but they're often locked to users who cannot afford to pay for a license. Further, their source code is proprietary and thus hidden. Is that wrong? No - developers need to earn a living too - but for students that sometimes means that paid CAS systems are hard to access outside the computer lab.

Our toolkit for solving basic differential equations in Python consists of the programming language itself, along with a few widely used packages:

- **Sympy**, to symbolically solve ODEs
- **Scipy**, to numerically solve ODEs
- **Matplotlib**, to plot solutions on graphs

## How to set up the toolkit

There are many ways to get access to this toolkit, but we will try to keep it as bare-bones as possible. If you already have a platform like Anaconda, you probably have these packages installed.

<g><b>Step 1</b>:</g> Download and install the latest version of Python: https://www.python.org/downloads/ .
Python comes with a piece of software called pip ("pip installs python") which helps you manage python packages.

<g><b>Step 2</b>:</g> Download and install sympy. You can do this by opening your terminal and typing

```console
pip install sympy
```

<g><b>Step 3</b>:</g> Download and install scipy. You can do this by opening your terminal and typing

```console
pip install scipy
```

If asked, make sure accept the download and installation any scipy dependencies (e.g. numpy).

<g><b>Step 4</b>:</g> Download and install matplotlib. You can do this by opening your terminal and typing

```console
pip install matplotlib
```

## Test that your toolkit is set up

To check that you have your toolkit set up, launch the Python interpreter. You can do this a few ways, for example by opening IDLE (software that comes bundled with Python), or:

On Windows, open either the command prompt or powershell and type

```console
python
````

On Linux and MacOS open the terminal and type
```console
python3
```

You'll should be greeted with something similar to:

```python
Python 3.10.3 (v3.10.3:a342a49189, Mar 16 2022, 09:34:18) [Clang 13.0.0 (clang-1300.0.29.30)] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> |
```

You can send commands to the python interpreter by typing them in now. Import scipy and print its version:

```python
>>> import sympy
>>> print(sympy.__version__)
1.13.1
```

Similarly for scipy and matplotlib:
```python
>>> import scipy
>>> print(scipy.__version__)
1.14.1
>>> import matplotlib
>>> print(matplotlib.__version__)
3.7.1
```

When you're done, quit the python interpreter to return to your terminal.
```python
>>> quit()
```
